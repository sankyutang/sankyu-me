三桥 · 三方向视觉提案

基于 huashu-design v3.5.0 窄桥流程：六候选 → 三真实差异骨架。目标不变——阅读优先 + 克制的咨询合作入口。本页只做方向对比，不混入站点文案。

请选一版。 DIR-1 指令报章 · DIR-2 错位工场 · DIR-3 珠江夜志。 截图见 artifacts；本目录仅预览，不部署、不改生产模板。
DIR-1

指令报章

Brutal / phosphor / 工程报头

黑白纸面 + 信号绿与警示红，报章式分栏。像工程师的日报：姓名即报头，文章是主栏，合作是侧栏短讯。
  • 骨架：报章分栏 + 波浪 SVG
  • 气质：冷静、可扫读、工程感
  • 适合：AI 实践长文为主的读者

DIR-2

错位工场

Hattori / 套印偏移 / 现场感

暖纸底 + 青绿 / 珊瑚 / 阳光黄，大字「桥」双色套印错位。一人公司的工场感：文章像现场卡片，合作是侧边窗口。
  • 骨架：巨字图腾 + 粗边卡片
  • 气质：有戏、手作、可互动筛选
  • 适合：想表达「人」与现场温度

DIR-3

珠江夜志

Deco night / 金玉夜色

深夜蓝底 + 金与玉色，衬线中文报头。广州珠江意象用 SVG 河线与楼影，夜读杂志感；咨询入口为克制金边面板。
  • 骨架：夜志双栏 + 装饰面板
  • 气质：沉静、地域、长文友好
  • 适合：强调广州与独立书写身份
