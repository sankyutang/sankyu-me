# 六张方向卡 → 三张完整版

秒数轮盘：`date +%S` = **27** → 网页 **08** 电影感声波可视化；东亚 **04** 上海摩登装饰艺术。

## 候选 A · 最佳设计师｜服部一成（玩味错位）
- **借的机制**：玩味集中在一处（巨字条纹错套印），信息栏反而排得老实；一条主大胆其余服务阅读
- **不借**：他的具体条纹色与手写标题气质；颜色从「独立开发调试时的终端光 + 广州霓虹」重长：薄荷绿底 `#E6F2EF`、青绿 `#0A6B62`、玫红 `#E11D48`、阳光黄 `#FFE566`（刻意避开暖奶油+陶土默认家）
- **主角素材**：程序化条纹巨字「桥」+ SVG 波线（代码/指令流）
- **骨架**：首屏左巨字右身份；下方文章横条列表 + 侧栏合作色块
- **胆量**：首屏半屏错位条纹「桥」
- **form**：一人公司像套印——有偏差才有手感，文章却要校准清楚
- **状态**：✅ 选入完整版 → **dir-2 错位工场**

## 候选 B · 最佳设计师｜杉浦康平（信息结构）
- **借的机制**：高密度但每块对应一个「位置」；环/刻度暗示周期
- **不借**：暖黑底曼荼罗外观；改用冷墨 + 金点，避免宗教装饰感
- **骨架**：中央时间环 + 四周文章引线
- **form**：从 2013 游记到 2026 AI 复盘的写作周期
- **状态**：备选（易用力过头，整页道具化）

## 候选 C · 现实参照｜Bloomberg Businessweek 粗野主义样张（board-2）
- **借的机制**：极端字号反差 + 规则线分栏切割 + 高信息密度；主色块压住正文
- **不借**：信号橙红默认；点缀改用终端绿 `#00A33E` + 超链接蓝 `#0000EE`（工程语境）
- **主角素材**：巨号日期数字 + 规则线网格；文章像报章栏
- **骨架**：报头 masthead → 双栏（主文栏 + 合作栏）→ 文章模块网格
- **胆量**：首屏「48」巨数字压摘要
- **form**：一周 48 条指令像一则工程报道
- **状态**：✅ 选入完整版 → **dir-1 指令报章**

## 候选 D · 现实参照｜overreacted.io（board-1）
- **借的机制**：个人技术写作以正文节奏为中心，少装饰
- **不借**：其极简外观（用户刚否定「太简约」）
- **状态**：备选（气质过静，易撞已否决的 B）

## 候选 E · 秒数轮盘｜网页 08 电影感声波可视化
- **借的机制**：全幅暗场 + 一条贯穿的「波形」作为母题（声音→改写为指令强度）
- **不借**：蓝紫渐变（避免 SaaS/AI 默认脸）；波形用磷光青绿单色
- **骨架**：暗场 hero 波形 + 下翻亮色文章栏
- **状态**：备选（与 dir-1 暗色工程气质可能撞家族；机制并入 dir-1 的次视觉）

## 候选 F · 秒数轮盘｜东亚 04 上海摩登装饰艺术
- **借的机制**：放射扇形几何 + 右侧日历格；商号信息通栏；双框
- **不借**：米黄纸色月份牌人像；改珠江夜色：墨绿 `#0F2E2A`、金 `#C9A24A`、朱红点缀；日历格改为文章日期格
- **主角素材**：SVG 扇形/阶梯塔 + 日期网格
- **骨架**：夜色报头 → 左身份/合作商号 → 右文章日历流
- **胆量**：首屏放射几何占半屏
- **form**：广州人开一人公司——都市夜色里的「开业」感，不是乡村手账
- **状态**：✅ 选入完整版 → **dir-3 珠江夜志**
